# Homework-5-Multiple-Regression
Multiple regression analysis and diagnostic evaluation of home sales data, focusing on mitigating heteroskedasticity and improving accuracy of our original given model.
Overview
This project we perform a multiple regression analysis on a housing price dataset to predict property prices. The goal was to evaluate a base model against various assumptions and develop an improved model by addressing issues such as heteroskedasticity and non-linearity in our given model
Methods we used Base Model: Estimated a linear relationship using bedrooms, bathrooms, sqft_living, yr_built, and education proportions. Conducted Residual vs. Fitted, Scale-Location, and VIF tests to identify violations of homoskedasticity and multicollinearity.
Findings: Explanatory Power: The improved model increased the Adjusted R  2   from 0.65 to 0.80, explaining 80% of price variance, and the log-price transformation successfully stabilized residual variance.
Tools: R, VIF, basemodel,improved model
